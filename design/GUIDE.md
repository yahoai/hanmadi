# 디자인 가이드 (v0.1)

제품 이름은 **Hanmadi**(한마디).

## 1. 무엇을 만드는가

- 대상: 여러 언어가 섞인 회의를 하는 직장인. 처음에는 도들랩 사내, 나중에는 글로벌
- 하는 일: 녹음을 넣으면 누가, 언제, 어떤 언어로, 무슨 말을 했는지 적고 번역까지 붙인다. 모든 처리는 그 컴퓨터 안에서 한다
- 주인공은 **전사문**이다. 나머지 UI는 전사문을 읽고, 듣고, 고치는 일을 돕는 도구로만 존재한다

## 2. 레퍼런스

| 앱 | 가져올 것 | 가져오지 않을 것 |
|---|---|---|
| Linear | 절제된 회색 체계, 1px 선, 정확한 정렬, 키보드 우선, 다크 모드 품질 | 개발자 도구 같은 밀도 |
| Granola | 문서를 읽는 것 같은 차분한 본문, 넓은 여백 | 크림색 배경 |
| Things 3 | 맥 앱다운 사이드바, 작은 동작 하나하나의 완성도 | 장식적인 일러스트 |
| Descript | 전사문과 오디오가 하나로 묶인 경험 (줄을 누르면 그 지점 재생) | 편집기 수준의 복잡한 도구 |

## 3. 원칙

1. **전사문이 화면의 주인이다.** 본문 폭은 720px로 고정하고, 도구는 위아래 가장자리로 보낸다
2. **코랄은 "지금"이라는 뜻이다.** 재생 위치, 처리 중 진행 막대, 지금 읽는 줄에만 쓴다. 주 버튼은 잉크(네이비) 색이다
3. **언어는 글자로 표시한다.** 한, 中, EN, 日. 국기나 "Korean" 같은 단어 대신 그 언어의 글자를 써서 어느 나라 사람이 봐도 바로 읽히게 한다
4. **원문이 먼저, 번역은 그 아래에.** 번역은 원문을 대신하지 않고 옆에서 거든다
5. **로컬 처리를 숨기지 않는다.** "이 컴퓨터 안에서만 처리합니다"는 기능이자 신뢰의 근거다. 시작 버튼 바로 옆에 둔다

## 5. 글꼴

- **IBM Plex Sans** 계열 하나로 통일한다: Plex Sans(라틴), Plex Sans KR, Plex Sans SC/TC, Plex Sans JP. 모두 OFL 라이선스라 앱에 같이 넣는다
- 고른 이유: 한 회의 안에 한국어, 중국어, 영어, 일본어가 섞여 나온다. 언어마다 글꼴이 달라지면 문단이 얼룩져 보인다. Plex는 네 언어를 같은 설계로 갖춘 몇 안 되는 가족이고, 기술 문서에서 온 단정한 인상이 "정확한 기록"이라는 제품 성격과 맞는다
- 본문 요소에는 `lang` 속성을 붙여서 중국어 줄은 SC, 일본어 줄은 JP 글꼴로 렌더링한다 (한자 모양이 언어마다 다르기 때문)
- 숫자(시간, 길이)는 `tabular-nums`로 자릿수를 맞춘다

| 단계 | 크기/줄간격 | 굵기 | 쓰임 |
|---|---|---|---|
| title | 28/36 | 600 | 전사 제목 |
| heading | 20/28 | 600 | 화면 제목 |
| section | 15/22 | 600 | 설정 묶음 제목 |
| body | 16/28 | 400 | 전사 본문 (CJK 가독성을 위해 줄간격 1.75) |
| ui | 13/20 | 400, 500 | 버튼, 목록, 입력 |
| meta | 12/16 | 400 | 시간, 길이, 보조 정보 |

대문자 라벨, 고정폭 글꼴 라벨은 쓰지 않는다.

## 6. 레이아웃

```
┌ rail 256 ───┬───────────────────────────────────────────────┐
│ ● ● ●       │ 제목                       [원문|함께|번역] 복사 내보내기 │
│ 검색  ⌘K    │ 날짜  길이  中 한 EN                           │
│ + 새 전사   │ ● Mina 54%  ● Wei 20%  ● 김민수 26%   검색  │
│ 진행 중     ├───────────────────────────────────────────────┤
│ 이번 주     │ 10:05  ● Wei 中                              │
│ 이전        │        你问一下 第一个有API吗 ...              │
│             │        물어봐 줘요. 첫째 API가 있는지 ...      │
│ 용어집      ├───────────────────────────────────────────────┤
│ 설정        │ ⏪ ▶ ⏩  10:05 / 55:27  [대화 지도: 화자별 막대]  1× │
└─────────────┴───────────────────────────────────────────────┘
```

- 본문은 왼쪽 정렬이다. 시간 칸 64px, 본문 최대 720px
- 맥: 타이틀 바를 숨기고 신호등 버튼을 사이드바 안에 둔다 (Tauri `titleBarStyle: Overlay`), 사이드바에 vibrancy를 쓴다
- Windows: 직접 그린 타이틀 바를 쓰고 오른쪽에 최소화/최대화/닫기를 둔다. Windows 11에서는 Mica를 쓰고, 그 아래 버전에서는 단색 배경으로 대신한다

### 이 앱의 상징: 대화 지도

재생 바 자리에 회의 전체를 화자별 줄로 그린 지도를 둔다. 한눈에 회의의 모양(누가 길게 말했는지, 어디서 대화가 빨리 오갔는지)이 보이고, 누르면 그 지점으로 간다. 재생 위치는 코랄 세로선이다. 화려함은 여기에만 쓰고 나머지는 조용하게 둔다.

## 7. 컴포넌트 규칙

- **버튼:** 주 버튼은 잉크 색 바탕(다크 모드에서는 반전), 보조 버튼은 테두리 없이 hover 때만 배경이 생긴다. 화면 하나에 주 버튼은 하나만 둔다
- **줄(turn):** 시간, 화자 점과 이름, 언어 글자, 줄 음성, 원문, 번역 순서로 놓는다. 고치기 버튼은 hover 때만 보인다
- **줄 음성:** 이름 옆에 그 줄 구간의 실제 파형과 길이를 작게 보여 준다. 누르면 그 줄만 재생하고 끝에서 멈춘다. 재생 중에는 파형이 왼쪽부터 코랄로 채워진다. 파형 막대 수는 길이에 비례하므로(최소 10, 최대 56개) 긴 발언은 눈으로도 길어 보인다
- **시간을 누르면** 그 지점부터 이어서 재생한다 (줄 음성과 달리 멈추지 않음)
- **번역 모드:** 원문 / 함께 / 번역. 기본값은 "함께". 번역 대상 언어는 앱 언어를 따르고 설정에서 바꿀 수 있다. 대상 언어와 같은 언어로 말한 줄은 번역하지 않는다
- **카드는 쓰지 않는다.** 묶음은 여백과 1px 선으로 나눈다
- **둥근 모서리:** 입력, 버튼 7px, 큰 영역 12px, 언어 글자 4px

## 8. 움직임

- 120-180ms ease-out. 튀는 애니메이션은 쓰지 않는다
- 움직이는 건 재생 위치와 지금 읽는 줄 강조 정도다
- `prefers-reduced-motion`이 켜져 있으면 스크롤도 바로 이동시킨다

## 9. 글 (UI 문구)

- 영어가 원본이고 한국어를 같이 낸다. 다음 언어는 중국어, 일본어
- 문장형 대소문자(sentence case)로 쓰고, 버튼은 하는 일을 동사로 적는다 ("Transcribe", "Export"). 결과 알림도 같은 동사를 쓴다 ("Exported")
- em dash, en dash, 물결표는 쓰지 않는다
- 날짜와 시간은 `Intl`로 지역 형식에 맞춘다

## 10. 키보드

| 키 | 동작 |
|---|---|
| Space | 재생 / 일시정지 |
| ← / → | 5초 뒤로 / 앞으로 |
| ↑ / ↓ | 이전 줄 / 다음 줄 |
| ⌘F | 전사문 검색 |
| ⌘K | 명령 팔레트 (전사 찾기, 화자 이름 바꾸기, 내보내기) |
| ⌘E | 내보내기 |

## 11. 접근성

- 본문 대비 4.5:1 이상 (라이트 `text` on `paper` 11.6:1)
- 모든 조작은 키보드로 가능하고 focus 링이 보여야 한다
- 화자는 색만으로 구분하지 않는다. 항상 이름이 같이 나온다
